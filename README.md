# APPE6 · Hub de apps para asociaciones juveniles

PWA (React + Vite + Supabase) para gestionar asociaciones juveniles.

- `app/`: la PWA. Copia `app/.env.example` a `app/.env` y rellena las claves de Supabase.
- `supabase/schema.sql`: esquema de base de datos con permisos (RLS).

Desarrollo: `cd app && npm install && npm run dev`
